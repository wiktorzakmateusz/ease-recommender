fit(X_train_csr)[source]

Train the model by computing the Gram matrix directly from sparse CSR, followed by high-precision GSL Cholesky inversion.

The underlying C engine utilizes cache blocking to maximize L1 cache hits and sequential memory prefetching, ensuring high-throughput inference even with massive item catalogs.

Parameters:

X_train_csr ((U, I) scipy.sparse.csr_matrix) – The user-item interaction matrix where rows are users and columns are items.

Returns:

The method computes and stores the dense weight matrix self.B in-place as a float32 contiguous array.
